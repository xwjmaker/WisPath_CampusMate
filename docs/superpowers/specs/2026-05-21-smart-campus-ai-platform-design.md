# 基于大模型的智慧校园AI服务平台 — 需求文档

**版本**: v1.0  
**日期**: 2026-05-21  
**学校**: 绵阳城市学院  

---

## 一、项目概述

### 1.1 项目背景

绵阳城市学院已有一站式学生服务社区的线下咨询管理平台，但学生获取校园信息仍依赖线下渠道，效率低、覆盖面有限。新生对校园环境陌生，在校生对办事流程不清楚，教师在日常事务处理上缺乏便捷工具。

### 1.2 项目目标

打造基于大模型的智慧校园AI服务平台，以一个具绵城特色的吉祥物智能体为核心交互入口，为学生和教师提供一站式线上服务。平台旨在：

- 帮助学生便捷获取校园信息、办理事务
- 为教师减负，提升工作效率
- 通过AI能力实现7×24小时智能问答服务

### 1.3 项目范围

本项目第一期聚焦Web端，覆盖：吉祥物智能体（问答/语音/形象）、校园风采展示（含VR实景）、统一登录门户（学生端/教师端分角色）。后续迭代扩展移动端和更多校园服务场景。

## 二、用户角色定义

| 角色 | 描述 | 核心需求 |
|------|------|----------|
| **新生** | 刚入学的学生，对校园环境、办事流程不熟悉 | 了解校园文化、校园导航、入学指南、办事流程咨询 |
| **在校生** | 已在校的学生，需要处理日常学习生活事务 | 课表查询、活动通知、校园资讯、事务办理指引 |
| **教师** | 需要处理教学管理相关事务的教职工 | 事务审批、公告发布、工作通知、减负提效 |
| **管理员** | 系统运维和内容管理人员 | 内容更新、用户管理、数据统计、系统配置、智能体知识库维护 |

## 五、数据需求

### 5.1 核心数据实体

- **用户**：学号/工号、姓名、角色（学生/教师/管理员）、学院、联系方式、导师信息（学生关联导师）
- **知识库**：分类、问题、答案、关联标签、更新时间
- **问答记录**：用户ID、问题、答案、时间、反馈
- **资讯公告**：标题、内容、发布人、发布时间、目标角色
- **校园风光**：标题、类型（风景/人物）、图片/VR资源、描述
- **消息通知**：接收人、内容、类型、是否已读、时间
- **成长记录**：学生ID、类型（荣誉/竞赛/获奖/社会实践）、标题、描述、时间、证明材料URL、是否可视化展示
- **日程**：用户ID、标题、描述、开始时间、结束时间、类型（会议/任务/提醒）、来源（手动/智能体同步）、状态
- **导师信息**：教师ID、研究方向、职称、简介、指导学生限额、竞赛指导记录、评分
- **审批工单**：工单ID、申请人、类型（请假/证明/报修）、内容描述、附件、审批状态、审批人、创建时间、处理时间
- **学业记录**：学生ID、学期、课程名称、成绩、学分、绩点、考试时间
- **图书信息**：ISBN、书名、作者、馆藏位置、借阅状态、预约状态
- **活动信息**：活动ID、标题、描述、时间地点、主办方、报名截止时间、参与人数上限
- **心理辅导**：预约ID、学生ID、咨询师、预约时间、状态、是否匿名
- **招聘信息**：企业名称、岗位、专业要求、薪资范围、发布时间、报名截止时间
- **新生流程**：学生ID、流程节点、完成状态、引导步骤、完成时间

### 5.2 数据流概要

```
用户 → 统一登录 → 角色识别 → 学生端/教师端
                                    ↓
                           吉祥物智能体 ←→ 知识库
                                    ↓
                             返回结果/推送通知
```
